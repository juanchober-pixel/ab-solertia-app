# AB Solertia - Sales Tracking App

Mobile web app for sales teams in the field. Built for distributors in Colombia.

### What it does
- Sales reps register visits with photo + real GPS location
- Managers see live dashboard with visits, orders and collections
- Login by company / seller
- Works on mobile as PWA

### Tech
HTML, JavaScript, Firebase, Vercel, PWA
